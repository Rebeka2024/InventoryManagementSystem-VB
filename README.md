# 📦 Inventory Management System (Visual Basic)

A Visual Basic application that simulates a basic inventory management system for tracking products and stock levels.

## 📌 Project Overview

This project was created to practice Visual Basic programming concepts while building a business-focused application. The program allows users to view inventory, search products, and identify low-stock items.

## 🚀 Features

- Add products to inventory
- View current inventory
- Search products
- Identify low-stock items
- Track product information

## 🛠️ Technologies Used

- Visual Basic
- .NET Framework
- Visual Studio
